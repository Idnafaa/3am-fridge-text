The 3AM Fridge Text: the one line a smart fridge texts its owner at 3am. An exhausted appliance, awake all night keeping the food cold, finally snaps — the light is on, nobody's home, and the leftovers are starting to talk back.

> 3am. I've been awake all night keeping your food cold. The light is on, nobody's home, and the leftovers are starting to talk back.

One line, 131 characters, inside the 140-character cap.

## Run it

```sh
python3 main.py
```

Writes the line to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt`).
